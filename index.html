Meet Miya

Miya is the one agent I talk to, on Telegram, about my training, my evenings, the family's weekends and where we eat. It has been live since June 8. Behind it, five specialists each own one job; Miya sends each ask to the one that owns it, checks the answer against the facts on record, and replies in one voice.

Why Miya checks before it speaks

A few weeks after I started talking to Miya, it told me something about myself that had never been true, in a flawless voice. I went to the prompt first. Ten patches later I was treating a systemic failure as bad luck, so I asked which layer was supposed to catch this. Nothing was.

I stopped adding features and rebuilt the core: the facts on record about me go in front of the model, and a validator checks every reply on the way out. A rule in a prompt is a request. A check in code runs every time. Replaying 126 of my real messages afterwards: internal-voice leaks went to 0%, and about one reply in twenty had a contradiction the validator caught.

Under the hood

Rahat is the platform under Miya, open source. Rules in code meet each message first, a specialist answers, a check runs on the way out, and every decision is written down. One message, end to end:

  1. /weekI ask Miya, on Telegram.
  2. A rule in codeOne of 16 rules claims it. No model.
  3. KobeComputes the answer from the watch data.
  4. The validatorChecks it against the facts on record.
  5. MeWord for word, and the decision is logged.
