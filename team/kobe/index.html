Kobe

The numbers.

Live, through Miya

The problem

“Where am I this week?” deserves a number, not a model's guess.

Why I have it

Training questions have exact answers in the data. Kobe computes them in code, so the answer is the same every time and costs nothing to produce.

What it does

  • Reads the watch data and what the gym has programmed for the week.
  • Answers the week, today, the plan and what's next, computed in code.
  • Hands workout design to Fraser and the evening wind-down to Huberman.

Where it helped

  • Everyday asks (the week, yesterday's numbers, tomorrow's workout) are answered in code with no model call, checked Oct 17.
  • Before Kobe answered from one ordered list of commands, the same kind of question kept breaking its routing: seven of its ten routing layers needed a fix within 48 hours. Now there is one list.

Every rep ends up as a number

Kobe turns days like this into the week's numbers: what I did, how it compares with the plan, and what's next, computed in code from the watch data. CrossFit is my reset; Kobe makes sure the numbers behind it are right.

How it works

The steps, in the order a message meets them. The names are the real components in the code.

  1. I ask a numbers question“Where am I this week?”
  2. A rule in code claims itNo model is called.
  3. Kobe's dispatcherOne ordered list of commands, all in code.
  4. The dataWatch data and the gym's week, from one SQLite file at home.
  5. Word for wordExact numbers go out exactly as computed, past the validator.

Not built yet

  • Kobe's model calls are logged, but not yet held to the shared budget gate.
