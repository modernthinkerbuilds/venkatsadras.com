The team · Agent

Genie

Weekends and the family calendar.

  • Behind Miya
  • Own bot since Aug 10

The problem

"What should we do this weekend?" comes up every week, and the answer is buried in a dozen event pages nobody has time to read.

Why I have it

Genie reads them for us, plans the weekend around what we've already decided, and keeps a household calendar that schedules instead of just listing.

What it does

  • Sends a daily digest of local events.
  • Plans weekends. If we already have a plan on file, it becomes the anchor and Genie fits around it.
  • Keeps a household calendar that never puts two things in one slot.
  • Tells us when its event feeds are stale or search is down, instead of guessing.

Where it helped

  • 121 event sources, 43 of them read in plain code with no model.
  • The first agent to start on its own front door and then join Miya. It took a weekend.
  • The first agent held to the structured-output contract from day one, with no exemption.

How it works

One message, step by step

Each step lights up in turn. The names are the real components in the code.

  1. TelegramIts own bot, or through Miya.
  2. Household gateOnly paired phones get in.
  3. Genie's intentsMatched in code: commands first, then plans.
  4. Plan or digestLive search for a plan; the events inventory for the digest.
  5. Genie's rulesOne thing per slot. At most six picks, three per source.
  6. CharterEvery write is checked before it happens.
  7. ReplySent as Genie wrote it, and recorded.

Not built yet

  • It doesn't write back to our phones' calendars yet.
  • Per-person preferences and a way to settle disagreements between us are designed, not built.
  • The Friday nudge exists but is off.
