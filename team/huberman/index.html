Huberman

The evening wind-down.

Live, through Miya · since Aug 24

The problem

My old cooldown routine was the same few drills every day, so I stopped doing it.

Why I have it

Huberman shows up on its own each evening with a cooldown built for the day I actually had, and it rotates through a library so it doesn't repeat itself.

What it does

  • Reads the day's training and recovery, and what the gym programmed.
  • Builds the session from a library of 25 drills, skipping the ones I've done recently.
  • Says so when it can't tell whether I trained, and offers the other version.

Where it helped

  • Live every evening since Aug 24, and on rest days since Aug 25.
  • Never empty: if the model can't answer, the session still comes from the library.

How it works

The steps, in the order a message meets them. The names are the real components in the code.

  1. 9:30 pmOnce a day, nobody has to ask.
  2. Read the dayTraining and recovery, from the database.
  3. Drill library25 drills. Recent ones are skipped.
  4. The modelWrites the coaching, with a 90-second limit.
  5. Never emptyIf the model fails, the library session still goes out.
  6. SentA missed send is retried the next minute.

Not built yet

  • It answers through rules and the evening timer; it isn't yet one of the agents Miya's model can hand a free-text ask to.
