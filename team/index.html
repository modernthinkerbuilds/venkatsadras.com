Six agents, one memory, one rulebook, one record of every decision. Miya is the one I talk to; five specialists each own one job. Bourdain is the first to prove itself on its own chat bot, with its own tests, before it joins Miya.

One badger per job, made with an image model and art-directed by me. The names are nicknames for the habits each agent borrows; no affiliation. Green answers through Miya. Gray is live on its own bot and joins Miya when it passes.

How they work together

I talk to Miya. Sixteen rules in code send each message to the agent that owns it; anything no rule claims goes to Miya's model, which asks the specialists and answers in one voice. A validator checks every reply before it reaches me, and every decision is recorded.
