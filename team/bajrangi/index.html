Bajrangi

The intern. A prototype.

  • Prototype
  • Since May 8

The problem

Before giving every agent one shared memory, I needed proof it worked for more than one kind of agent.

Why I have it

Bajrangi is a stub with its own kinds of things to remember, on the same memory as everyone else. It proved the memory didn't quietly assume everything belonged to Kobe.

What it does

  • No front door and no chat. Other agents use its memory adapter.

Where it helped

  • Proved the shared memory works across domains. Huberman still uses its adapter today.

How it works

One message, step by step

Each step lights up in turn. The names are the real components in the code.

  1. Another agentNeeds to remember something.
  2. Shared memoryOne memory, one SQLite file at home.
  3. Bajrangi's adapterIts own types, on the shared store.
  4. Back to the agentWithout leaking anyone else's assumptions.
